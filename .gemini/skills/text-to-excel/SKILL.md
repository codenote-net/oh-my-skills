# Text to Excel

## Overview

This skill provides the functionality to convert textual data into a structured Excel spreadsheet. It is particularly useful for taking the output from the `pdf-to-text` skill and organizing it into a tabular format within an Excel workbook. The skill supports using a pre-existing Excel template to ensure consistent formatting and data placement.

## Core Capabilities

1.  **Text to Excel Conversion**: Processes plain text input and writes extracted data into an Excel (`.xlsx`) file.
2.  **Template Support**: Optionally uses a user-provided Excel template to maintain desired formatting, formulas, and layout in the output.
3.  **Customizable Parsing Logic**: The underlying Python script can be extended with regular expressions, keyword searches, and other parsing techniques to accurately extract information from varied text structures.

## How to Use This Skill

This skill is primarily driven by the `scripts/text_to_excel.py` Python script.

### 1. Prepare Your Input Text

Ensure you have your text content ready. This could be a `.txt` file generated by the `pdf-to-text` skill or any other plain text document.

### 2. (Optional) Prepare Your Excel Template

If you wish to use a pre-formatted Excel file, create your `.xlsx` template. Refer to the `references/excel_template_guide.md` for best practices on creating effective templates.

### 3. Run the Conversion Script

Execute the `text_to_excel.py` script from the command line.

**Basic Usage (creating a new Excel file):**

```bash
python scripts/text_to_excel.py \
    <path_to_input_text_file.txt> \
    <path_for_output_excel_file.xlsx>
```

**Using an Excel Template:**

```bash
python scripts/text_to_excel.py \
    <path_to_input_text_file.txt> \
    <path_for_output_excel_file.xlsx> \
    --template <path_to_excel_template.xlsx>
```

Replace `<path_to_input_text_file.txt>`, `<path_for_output_excel_file.xlsx>`, and `<path_to_excel_template.xlsx>` with your actual file paths.

### 4. Customize Parsing Logic (Advanced)

The `scripts/text_to_excel.py` contains example parsing logic. For accurate data extraction specific to your documents, you will need to modify this script.

Refer to the `references/parsing_rules_guide.md` for detailed instructions and examples on how to implement custom parsing rules using Python's `re` module (regular expressions) and `openpyxl` for writing to Excel cells.
